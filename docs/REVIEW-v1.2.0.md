# v1.2.0 视觉与系统复核 · 本命神兵

## 范围

本版增加凡界四槽装备与本命神兵，但不把仙界五槽并入凡界，也不重新设计既有境界、妖王、天劫和无尽诸天数值。

## 数据与玩法复核

- 四个凡界槽：兵器、法宝、法衣、佩饰；行囊上限 12。
- 24 件基础装备，覆盖四槽各 6 件；9 件特殊神兵构成 3 条路线 × 3 阶段。
- 掉落由本世 seed 和一次性来源键确定，不消费主状态 RNG；重复来源不能重复领奖。
- 妖王、天地印证和天劫是高价值装备来源；普通历练/狩猎允许确定性落空。
- 鉴定免费；归炉产生器蕴；温养四段且必定成功；没有耐久和 `+N` 强化显示。
- 本命神兵以真实战斗/妖王/天劫积累历练，达到固定阈值后由玩家主动蜕变。
- 凡界装备效果只进入凡界 `effects()`；仙界五槽继续由 `FSEvolution` 单独管理。
- v5→v6 旧档只增加空装备态，不补发旧装备或虚构掉落历史。

## UI 复核

- 顶部「行囊 n/12」只在入世后出现；装备对话框集中呈现四槽、器蕴、行囊和本命神兵历练。
- 未鉴定器物不泄露具体名称；鉴定后才显示名称、说明和槽位操作。
- 已穿戴装备不能归炉，避免误删当前 Build；卸下后可归炉。
- 本命神兵显示路线和阶段，不把蜕变画成普通强化等级。
- 神兵蜕变复用 v1.1.0 单一重大事件层，避免多层遮罩。

## 浏览器验收要求

正式证据以 `output/playwright/v1.2.0/latest-isolated-run.json` 指向的隔离运行目录为准。除既有完整凡界、轮回、仙界、无限进化与文件模式外，本版必须在真实 DOM 中打开装备行囊、完成一次鉴定和一次穿戴、刷新页面并确认装备状态不变，同时对装备对话框执行 320 / 360 / 390 / 430 / 768 / 1280 六宽度检查。

桌面 Chromium 验收不等同于实体手机触控、长期真人留存或主观美术审美测试。
