# v1.8.0 视觉与系统复核 · 灵兽仙缘

## 目标

增加一条长期陪伴成长线，但不把《我欲飞升》改成宠物收集游戏。

## 复核项

- 初始种族固定 4 个，一世只允许 1 个主灵兽位。
- 每种灵兽只有 2 条永久分支；选定后刷新、导入和后续进化都不能改支。
- 五阶段成长由单一有界材料驱动，材料消费可见且无强化失败。
- 灵兽效果进入既有 Build 解释链，不建立第二套隐藏战力系统。
- 真灵到仙兽要求已经飞升且实际进入仙界。
- 新一世不继承本世灵兽数值；旧 v10 迁移只补空状态。
- 灵兽面板在 320 / 360 / 390 / 430 / 768 / 1280 六宽度无溢出，按钮触控目标不低于 44px。

浏览器专项应通过真实 DOM 完成结契、材料准备后的两次进化、永久分支、刷新恢复与 Build 来源检查，并独立验证仙兽阶段的仙界入口门禁。
