# v1.6.0 视觉与系统复核 · 宗门时代

## 目标

把宗门作为“传承 + 一次性事件 + Build 来源”接入凡界，而不是新增管理后台。

## 复核项

- 四宗各有 1 被动、1 传承、3 节成长事件与 1 宗门大事件。
- 不存在贡献币、工资、每日任务、职位树或宗门经营循环。
- 谢绝后仍可重新考虑；主动叛宗后今生不可重新拜入同宗。
- 高境界入宗按顺序补事件，同一事件只结算一次。
- 入门事件解锁传承；离宗后被动、传承和 Build 宗门来源立即撤销。
- 护宗 / 离宗 / 叛宗结果都有明确可追溯记录。
- v8→v9 只补空宗门态，不伪造旧档历史。

## UI

宗门入口位于「本世道途」二级操作区。未入宗时显示四宗对照卡；入宗后显示当前传承、事件进度、一次性选择与最近记录。320 / 360 / 390 / 430 / 768 / 1280 六宽度均需无横向滚动，按钮触控区不小于 44px。

浏览器专项必须真实执行：谢绝一个宗门 → 拜入另一个宗门 → 处理入门事件 → 刷新恢复 → 核对 Build 来源 → 主动离宗 → 核对宗门效果与 Build 来源消失。正式证据以 `output/playwright/v1.6.0/latest-isolated-run.json` 指向的隔离目录为准。
