# v1.3.0 视觉与系统复核 · 万法归一

## 目标

让玩家能回答“为什么这一世是这个 Build、为什么这个协同生效、它现在具体改变了什么”，同时不把已有六大道途改造成锁定职业。

## 复核项

- 10 类标签名称固定，来源来自真实当前状态。
- 15 条协同全部在规则表声明所需标签、效果字段与解释文本。
- `evaluateBuild` 不使用 RNG、不改状态、不推进 revision。
- 主脉 / 辅脉只在六条核心道途标签中选择；雷霆、生存、爆发、成长仍可作为辅助标签参与协同。
- Build 效果逐条相加，没有第二个隐藏倍率入口。
- 卸下装备后立即重算，依赖该装备的协同消失。
- 原六大道途识别、轮回、仙界和五槽系统不被替换。

## UI

主界面的「本世道途」增加 Build 主/辅脉与协同数量；「查看协同」对话框按来源 → 协同 → 当前效果展开，并可查看全部来源。小屏使用单列协同卡，桌面使用双列；无协同时提供明确空状态。

浏览器专项必须在金丹检查点打开真实 Build 对话框，确认纯评估器与 DOM 协同数量一致、六宽度布局通过，并验证打开后存档逐字节不变。正式证据以 `output/playwright/v1.3.0/latest-isolated-run.json` 指向的隔离目录为准。
