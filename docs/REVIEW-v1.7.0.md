# v1.7.0 视觉与系统复核 · 天命人生

## 目标

让现有出身在整世中至少回响两次并形成一个重大选择，同时保持“可以拒绝、不会锁职业、不会重复领奖”。

## 复核项

- 四种既有出身各 3 个节点：2 次后续回响 + 1 次重大选择。
- 事件只由出身与当前境界决定，不消耗 RNG。
- 每个节点都提供三条明确路线，其中至少一条可以拒绝/放下且无强制奖励。
- 拒绝也写入完成记录，刷新后不会重复出现或重复领奖。
- 人生余波是小幅、公开、可解释效果，并成为 Build 真实来源。
- 重大选择单独保留，供 v1.10 因果系统追溯。
- v9→v10 只补空人生态，不伪造旧档历史。

## 浏览器专项

使用真实筑基检查点触发对应出身的第一段回响，核对 3 个选择、六宽度布局、结算一次、Build 来源出现、刷新后存档逐字节保持，再打开人生历史复核已完成节点。拒绝路线的存在同时由 DOM 和单元测试覆盖。
