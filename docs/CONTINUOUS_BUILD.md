## 范围约束与实现判断

1. 首次高阶历练本来就保底触发印证事件，因此「寻天地印证」直接进入待选择事件，不制造多余的自动循环，也不自动替玩家选分支。
2. 无用户提供的音乐文件，声境使用原创 Web Audio 程序合成的低频铺底和五声音阶稀疏拨弦；不是录制 BGM，不调用收费服务，不外链音源。
3. 保留凡界飞升正式结局，再给「踏入仙界」入口。旧通关档仍可停在原结局或转世，不强行开启新篇。
4. 无尽数值不能溢出为 Infinity；使用可序列化的数量级表示，保留固定长度历程与有限槽位。
5. 时长、留存、真机兼容均不由自动测试虚构。桌面 Chromium 视口回归与真实手机验证分别表述。
