## ST-03 跨篇桥梁与存档迁移

内容：

- 增加 `mortalBridge`、`immortalBridge` 的显式 schema 与 validator。
- 旧 v3.0.9 已飞升但没有 bridge 的存档，只能从当前真实完成存档安全生成一次；禁止根据不完整日志猜测数值。
