## 本次续接的修复

窗口注册器不再用空 catch 隐藏异常。同一个窗口重绘前也会释放旧绑定；进入开局、剧情阶段、仙界或创世旧页面时会显式释放 V3 活动窗口。当前采用同步替换渲染，不能称为完整的 Unity 运行时或 Lua 窗口系统。

修复通用炼器配方仅因 `path=any` 就显示可炼制的问题：仍必须有已穿戴、已鉴定的本命兵器。过期的界面配方选择回退到现有配方，不因不存在的 ID 崩溃。秘境或行旅占用时，炼器和物品动作按原引擎限制禁用。

行囊整备显示 6/8 盘缠、1 伤药与实际行动年数；温养显示器蕴费用，神兵蜕变显示当前历练与阈值。补充直接卸下和蜕变入口。山海页在寿元不足以出发时不再提供可点击的启程按钮。

V3 主内容与底栏改为两个独立网格行，底部安全区参与导航高度计算；行囊物品列表占用剩余空间并独立滚动，不再叠加多个固定高度估算。
