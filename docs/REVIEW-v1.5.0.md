# v1.5.0 视觉与系统复核 · 秘境降临

## 系统复核

- 三座秘境固定 3 / 4 / 5 层，境界入口清晰且不重叠。
- 普通层至少存在一条非失败路线；Boss 层始终可选择安全退出而不是强制送死。
- 1,200 个确定性 seed 模拟无死循环，层数不会越界。
- 路线、异象与 Boss 判定由秘境子 seed 固定，刷新不重抽。
- 失败只结束秘境；主线 phase、寿元、轮回与仙界状态不被破坏。
- Boss 首胜来源只写一次；重复完成不重复发首胜装备。
- 最近历史上限 12，active 结束后临时增益不保留。

## UI 复核

- 顶栏「秘境」只在凡界 playing 阶段出现；active 时显示当前层数。
- 风险、门槛、预计收益在点击前可见。
- 「安全退出」始终存在，并明确说明保留规则。
- 刷新后回到同一层同一候选；主界面在 active 时只提供“返回秘境”。
- 320 / 360 / 390 / 430 / 768 / 1280 六宽度检查无横向滚动。

正式证据由 `npm run test:browser` 的 v1.5.0 隔离目录记录。
