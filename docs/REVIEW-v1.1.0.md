# v1.1.0 视觉复核 · 灵台焕新

## 范围

本版只改变表现层，不改变凡界战力、掉落、轮回道痕、仙界或五槽进化的确定性结算。

## 复核项

- 首屏主信息顺序固定为：当前境界 / 战力与修为 → 当前事件 → 主操作 → 道途与辅助入口。
- 通用大卡片进一步减弱，状态区与事件区改为上下边界和留白分层。
- 七阶段背景继续使用原有 SVG；新增前景薄雾层仍由 CSS 合成，不产生网络或图片依赖。
- 修为、吞噬、元气获得统一短促跳字；同屏最多保留 4 条，不写入存档。
- 突破、异变、融合、雷劫和飞升共用单一重大事件层；新事件会替换旧事件，不允许叠层。
- `prefers-reduced-motion` 下奖励跳字和重大事件遮罩直接关闭，状态结算与操作入口不受影响。
- 音频仍为 Web Audio 程序合成；重大节点增加短促高频瞬态，但不增加 MP3/WAV 或新的游戏 RNG。

## 自动证据

正式验收以 `output/playwright/v1.1.0/latest-isolated-run.json` 指向的隔离浏览器证据为准；截图矩阵需覆盖 320 / 390 / 430 / 1280 px 扩展回归，同时主流程仍由既有浏览器套件覆盖。布局检查用于核对无横向滚动、可点击目标尺寸、对话框边界和资源加载。

## 未宣称

桌面 Chromium 截图矩阵不等同于实体 iOS/Android 真机、主观动画审美或主观听音测试。
