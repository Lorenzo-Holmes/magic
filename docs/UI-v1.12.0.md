# v1.12 视觉与交互调整

用户指定参考：https://github.com/lehuo9248/xianxia-idle-game 。只参考三栏组织、深色卡片、金色高亮、青玉进度条与图标风格，未复制该项目代码或素材。

中央修炼卡使用可替换的黑色打坐 SVG 剪影，不固定人物性别、面貌或服装；金色法阵与弱光建立视觉焦点。用户提供的人物参考只用于理解打坐位置，详细人物生成稿未纳入生产包。山水背景沿用上一版原创本地素材，来源见 UI_ART-v1.11.0.md。

旧暖纸事件样式已移除，事件、来源说明与禁用按钮在深色背景上分别保持可读。法阵遵守减少动态设置；不引入外部字体或运行时依赖。
