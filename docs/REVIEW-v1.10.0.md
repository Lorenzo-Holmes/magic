# v1.10.0「因果天网」视觉与交互复核

## 复核范围

- 因果面板显示来源、关系、强度和可触发阶段，不提前剧透完整结果。
- 待偿因果使用单一高亮事件块，三条选择均为 ≥44px 可触控目标。
- 已知因果与已偿摘要采用紧凑列表，不引入任务红点、独立货币或 Dashboard 卡片矩阵。
- 320 / 360 / 390 / 430 / 768 / 1280 六宽度由自动浏览器验收再次覆盖。

## 设计边界

- 因果不是随机惩罚；所有结果都从已记录来源进入预置事件。
- 活跃因果 ≤24，摘要 ≤40；UI 不展示无限历史。
- 未处理因果不阻塞主线，飞升后仍可进入仙界。
- 本版不宣称完成实体手机、主观留存或长期真人游玩验证。
