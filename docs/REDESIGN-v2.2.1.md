# v2.2.1 UI 修正：从“场景化网页”改成“场景即界面”

## 原因

v2.2.0 虽然引入洞府场景，但三个主操作仍使用半透明矩形卡片，人物入口也仍是卡片节点；全局顶栏与资源条继续占据一级游戏页面。因此信息结构有场景感，视觉语言仍然偏 Web Dashboard。

## 参考安装包得到的约束

本次只复用此前对《一念逍遥》APK 的结构分析结论，不复制其美术、字体或代码：一级玩法以全屏场景为主；HUD 直接叠在场景；功能入口以空间位置、圆形图标和短标签识别；人物页由角色主体与周围装备/功能槽构成；世界地图本身承担导航；详细规则在进入功能后再展开。

## 实施

- 修行：隐藏一级通用 Topbar/Resource Overview，把境界、战力、修为、年龄、元气、盘缠、行粮、音景与存档全部放回洞府场景。
- 修行热点：闭关、山海、机缘取消矩形背景和玻璃卡片，改成圆形印章式入口 + 短标签。
- 山海：标题进入地图舞台，地图在移动端占据除底栏外的完整首屏；路线和整装信息位于地图下方滚动区。
- 行囊：取消三条菜单列表，改成独立行囊舞台；神兵、丹器、灵兽围绕中央“囊”入口布局，盘缠/行粮/伤药/伤势作为场内底部 HUD。
- 人物：去掉角色场景前的规则说明，角色舞台成为首屏；命册、神兵、大道、灵兽改成圆形槽位围绕人物，基础属性置于场内底部；根基说明移到场景之后。
- 导航：四个一级页面统一保留底部四项导航，并使用深墨色底、圆形符号和当前页强调。
- 390×844 实测：四个一级舞台均从 y=0 铺到 y=786，底栏 y=791~844，document scrollWidth=390，无横向溢出。

## 边界

本版本仿照的是页面层级、空间构图、HUD 密度、入口形态和交互节奏。没有将参考 APK 中的 Sprite、Texture、Prefab、字体、Lua 或其他专有资源加入项目。
