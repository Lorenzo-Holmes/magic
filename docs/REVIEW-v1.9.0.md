# v1.9.0 视觉与系统复核 · 丹器百艺

## 目标

让采集、炼丹和本命炼器形成有用但有界的辅助循环，不引入自由配方爆炸、耐久或强化失败。

## 复核项

- 10 丹方 / 8 材料 / 3 炼法 / 4 本命炼器配方数量固定。
- 普通丹与异丹逐枚保存；同 seed、同炼制序号、同炼法结果一致。
- 每次炼制真实扣除配方材料；材料、丹药、来源和历史均有上限。
- 临时 Build 丹效有明确剩余次数，结束后 Build 来源消失。
- 炼器只增加当前已穿戴本命兵器历练，不出现强化失败和第二套耐久。
- 丹器面板六宽度无横向溢出，30 个炼丹手法按钮仍满足 44px 触控目标。

浏览器专项必须真实完成炼丹、服丹、刷新恢复、Build 来源和一次本命炼器，并与生产 ZIP SHA 对齐。
