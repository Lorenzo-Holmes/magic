# 《我欲飞升》实现基线 v0.6.1 · 节奏打磨

## v0.6.1 增量约定

保留 v0.6.0 下述玩法。连续闭关额外预留一次闭关的寿元，不自动突破或完成事件；寻天地印证只转发一次保底历练，停在选项页。首局批注在轮回册保存关闭状态，首次飞升自动关闭。主战力数字使用万/亿缩写，点按可看完整数字；存档数值不缩减。败退计数不随最多 100 条日志截断而丢失，旧档缺失记录时不补发无暇飞升。逆寿成仙以入劫前大乘寿元为分母。

## 1. 本版目标

v0.5.0 完成了从凡人到飞升的凡界主线，v0.5.1 用七阶段境界背景解决长线游玩时世界缺少视觉层级的问题。v0.6.0 处理下一项核心问题：**第一世结束以后，玩家为什么还要再开一局。**

本版不扩大仙界，不增加宗门、炼丹、炼器或付费系统。它在现有完整主线之外增加一层轻量跨局结构：

```text
本世真实选择
→ 流派识别
→ 图谱与称号记录
→ 三选一凝练道痕
→ 下一世一次性继承
→ 开局流派保底 + 对应天劫额外路线
→ 道痕被消费
```

设计原则是“提供新的开局方向，而不是永久堆叠战力”。凡界首遇妖蟒、筑基复仇、金丹融合、妖王和天劫的原有压力结构必须继续成立。

## 2. 保留的凡界主循环

```text
抽先天天命
→ 属性加点 / 灵根 / 出身
→ 闭关 / 历练 / 狩猎
→ 遭遇强敌
→ 逃跑 / 战斗 / 吞噬
→ 修为增长
→ 大境界突破
→ 三选一天命
→ 首次异变
→ 金丹融合
→ 三眼妖王
→ 五境天地印证
→ 三重天劫
→ 飞升
```

境界、阈值、战力倍率、敌人、异变和融合的基础数值结构沿用 v0.5.x。

## 3. 境界与战力

| 境界 | 修为阈值 | 基础寿元 | 战力倍率 | 闭关耗年 |
| --- | ---: | ---: | ---: | ---: |
| 凡人 | 100 | 80 | 1 | 4 |
| 炼气 | 500 | 120 | 6 | 7 |
| 筑基 | 2,500 | 200 | 50 | 10 |
| 金丹 | 12,000 | 500 | 500 | 18 |
| 元婴 | 60,000 | 1,000 | 5,000 | 35 |
| 化神 | 300,000 | 3,000 | 50,000 | 70 |
| 炼虚 | 1,500,000 | 8,000 | 500,000 | 140 |
| 合体 | 8,000,000 | 20,000 | 5,000,000 | 280 |
| 大乘 | 45,000,000 | 50,000 | 50,000,000 | 560 |
| 渡劫 | 三重天劫 | 100,000 | 500,000,000 | 不再普通闭关 |

基础战力：

`5 + 根骨×1.2 + 悟性×0.8 + 神识×0.8 + 气运×0.2`

最终显示战力近似：

`基础战力 × 境界倍率 × 境界进度 × (1 + 全局增益) × 元气系数`

有效战力比 R：

- R < 0.55：十死无生，不允许正常送死；
- 0.55～0.85：凶险；
- 0.85～1.20：势均力敌；
- 1.20～2.00：优势；
- 2.00～3.00：碾压；
- R ≥ 3：蝼蚁。

R ≥ 2 必胜且不损失元气。轮回道痕不参与该公式。

## 4. 本世道途识别

`src/meta.js` 根据已经存在的状态计算六类路径分数。识别结果是解释层，不写回战斗状态，也不消耗随机数。

### 4.1 六类路径

| ID | 名称 | 主要计分信号 |
| --- | --- | --- |
| `devour` | 吞噬进化流 | 吞噬天命、吞噬次数、妖蟒血、吞噬融合、吞噬破局 |
| `sword` | 雷剑破界流 | 剑道天命、青云剑诀、雷剑体、剑道 Boss/天劫路线 |
| `body` | 不灭肉身流 | 根骨、肉身天命、赤鳞、肉身融合、承伤路线 |
| `soul` | 神魂妖瞳流 | 神识、蛇瞳、九幽妖瞳、看破妖眼与心魔 |
| `fortune` | 天命气运流 | 气运、气运天命、天命护体、命数路线 |
| `insight` | 悟道归一流 | 悟性、修炼天命、五行归一、悟道路途 |

最高分路径成为当前“本世道途”。按分数显示初显、成形、稳固或圆满，并给出最多三个可核对的判定信号以及与当前主线进度相符的下一步提示。

### 4.2 非干预约束

- 识别函数不得修改本世存档；
- 不改变天命、属性、修为或战力；
- 不因打开命册、图谱或刷新页面推进 RNG；
- 携带道痕只给对应路径很小的识别信号，不伪装成本世已经成型。

## 7. 轮回道痕

### 7.1 候选生成

飞升或死亡后，从六类路径分数中取前三名作为候选。候选显示契合分、判定依据、下一世影响和对应天劫用途。玩家只能选一枚；重新选择会替换，而不是叠加。

### 7.2 当前六枚道痕

| ID | 道痕 | 开局影响 | 天劫阶段 |
| --- | --- | --- | --- |
| `devour` | 噬界残痕 | 至少一张吞噬天命 | 天门终劫 |
| `sword` | 剑心余烬 | 至少一张剑道天命 | 天门终劫 |
| `body` | 不灭骨印 | 至少一张肉身天命 | 九霄雷劫 |
| `soul` | 照幽灵纹 | 至少一张神魂天命 | 问心魔劫 |
| `fortune` | 天命余辉 | 至少一张气运天命 | 天门终劫 |
| `insight` | 悟道残卷 | 至少一张修炼天命 | 问心魔劫 |

### 7.3 开局保底

带痕创建新存档时，先照常生成八张天命并保留第一张玄品以上保底。如果八张中没有对应流派，替换最后一张普通候选为该路径天命。重抽继续执行同一规则。

该规则只保证“至少出现一项”，不指定具体单卡，不提高稀有度，也不自动选择。

### 7.4 一次性消费

轮回册中的 `nextTrace` 在新存档创建成功后清空，道痕 ID 写入新存档的 `carriedTrace`。该存档整个生命周期都能识别这枚道痕，但它不会自动传到下下一世。新一世结束后必须重新从本世候选中凝练。

### 7.5 天劫路线

每枚道痕只在配置的天劫阶段追加一个可选路线。成功采用后，路线 ID 写入 `tribulationRoutes`，供称号、图谱和命册使用。道痕路线与普通专属路线采用同一战力判定，不保证无条件成功。

## 8. 连续闭关

`cultivate-to-ready` 是一项显式玩家操作，不是后台自动运行。它循环使用原有闭关逻辑，并在以下条件停止：

1. 强制赤鳞妖蟒遭遇出现；
2. 当前境界修为达到阈值；
3. 下一次闭关会触及寿元上限；
4. 状态进入死亡、阻塞事件、突破或其他不可闭关阶段；
5. 安全上限 64 次循环。

连续闭关不自动突破、不解决事件、不选择天命、不挑战妖王、不执行天地印证，也不进入渡劫选择。多次闭关会合并当前事件说明，并在日志中保留汇总。

## 9. 原有关键因果

### 9.1 赤鳞妖蟒

首次妖蟒固定 150 战力。正常开局玩家约 20～40 战力，只能逃生，并由此获得基础吞灵诀。筑基后妖蟒仍为 150，玩家可以直接吞噬或镇杀后炼化遗蜕，两条路线都进入首次异变。

### 9.2 金丹融合与三眼妖王

首次异变必须带入金丹并形成三项融合候选。三眼妖王固定 24,000 基础战力，至少完成两处金丹机缘且存在可行路线后才能挑战。本版额外记录实际破局路线，但不改变旧有路线条件。

### 9.3 天地印证与三重天劫

元婴、化神、炼虚、合体、大乘每境至少完成一次世界尺度事件才能破境。大乘以后依次经历九霄雷劫、问心魔劫和天门终劫。三劫全部完成才设置 `ascended=true`。

## 10. 正式终点

飞升页继续明确显示“天门已开”和“你已飞升”，保留旧敌 150、玩家数百亿战力、仙界噬灵虫约玩家 1.7 倍的三段反差。

仙界噬灵虫仍是彩蛋，不是可操作的仙界主线。v0.6.0 的新增终点操作是凝练道痕和查看图谱，而不是继续堆叠未完成关卡。

## 11. 本世存档 v4

v4 在 v3 基础上增加：

- `carriedTrace`：这一世携带的道痕；
- `bossRoute`：击败三眼妖王时实际采用的路线；
- `tribulationRoutes`：三劫成功采用的路线；
- `batchCultivations`：连续闭关实际完成次数。

迁移顺序为 v1 → v2 → v3 → v4。旧 v3 飞升存档保留完成状态，并以 `legacy` 占位三次旧天劫记录；旧版没有保存的具体路线不会被猜测补写。

## 12. 轮回册 v1

轮回册独立于本世存档，包含：

- 已结束与已飞升次数；
- 八类图谱发现集合；
- 最近 50 世摘要；
- 下一世待继承道痕及来源种子。

本世存档与轮回册可分别导出和导入。导入本世不会覆盖跨局发现；导入轮回册不会篡改当前角色。损坏、未知 ID、重复发现和越界统计会被验证器拒绝。

## 13. 视觉系统

v0.5.1 的七阶段背景完整保留：黑风岭、凌云之巅、丹霞悬境、诸域云上、界外星海、九霄劫天和天门彼岸。妖蟒、融合、妖王、高阶事件、渡劫与飞升继续使用独立气氛覆盖。

新增界面沿用命册视觉：道途提示是窄幅批注，图谱使用可折叠册页，道痕候选使用三列/移动端单列结构。没有改造成手游大厅或卡牌抽奖界面。

## 14. 生产与测试契约

生产包白名单为 15 个文件，新增 `src/meta.js`，不包含 README、文档、截图、测试、字体或开发依赖。内部包体目标 3 MB，平台上限 10 MB。

当前测试层次：

- 状态机、迁移、连续闭关和 800 局随机仿真；
- 流派、称号、图谱、轮回册和道痕单元测试；
- 七阶段场景映射和异步背景加载测试；
- 实际 DOM 点击完整飞升；
- 结算三选一、下一世继承与消费；
- 320 / 390 / 430 / 1280 px 主页面及对话框布局；
- 本世/轮回册导入导出、损坏数据、存储拒绝和刷新续接；
- 源码、`dist`、ZIP 解压目录的 `file://`；
- reduced-motion、资源失败、控制台错误和外部请求。

最终实测数字和候选包哈希记录在 `docs/V0.6.0_ACCEPTANCE.md`。

## 15. 后续边界

下一阶段可以在真实玩家试玩后决定：先压缩重复操作、补充轻量声音，或制作小规模仙界序章。正式仙界不应只把数值继续乘百，而应引入法则碎片等新的吞噬对象。

本版不实现永久战力树、跨局货币、宗门经营、炼丹、炼器、道侣、宠物、PVP、每日任务、广告奖励或付费抽卡。
