# v2.1.0 山海行旅：需求与实施约定

## 用户需求

用户认为当前 UI 有明显模板感、功能杂乱、难度低、探索方向少；要求参考 lehuo9248/xianxia-idle-game 的源代码重新设计，并用内置 imagegen 生成游戏美术。用户已确认难度选择为“有风险但能挽回”。以 v2.0.0 已验收提交 a442e50e92a6f894c66e423311497939bd502432 为恢复点，保留各旧版 ZIP。

## 已核对的问题

现有闭关可连续补满修为并恢复元气；突破缺少独立的准备过程。旧秘境每层保证 herb/page 安全路线，方向主要表现为随机选项而非玩家选择目的地。主画面同时放置人物、资源、主事件、道途、灵兽、丹器、顶部入口和十二个导航按钮，相同功能重复出现。

参考源码 pages/index/index.vue 采用 currentTab 切换中央单一功能面板；本次采用这个信息结构原则，重新组织本项目现有内容，不照搬其全部功能数量。参考链接：https://github.com/lehuo9248/xianxia-idle-game。

## 新的玩法循环

草庐准备 → 选择地区和目标 → 三段行旅中取舍 → 带伤或带宝返回 → 调息、装备、补给 → 以阅历稳固根基 → 突破并解锁新区域。

行旅提供六个地区和每地三条不同目标路线。地域有独立资源偏向、事件和解锁条件；三种处事方式用不同属性与物资应对，预先展示成功率、消耗和后果。战力不直接解决所有采集、交涉、勘察。途中奖励暂存，主动撤退保留大部收益，失败损失部分暂存收益并留下可治疗的伤势；不会因一次行旅失败直接杀死角色。路线及结果可复现，刷新不重抽，存档保留途中状态。

新局使用行旅难度：突破需要修为与根基；根基来自外出经历，闭关不能包办全部成长。旧档迁移保留旧主线规则，允许玩家明确启用新的行旅规则。旧档不会凭空获得过去未记录的探索成果。应同时报告经典主线回归和新玩法风险/策略仿真，不能用旧版 100% 通关替代新难度的验证。

## 界面和美术

一级入口缩为修行、山海、行囊、人物。其余功能在所属页逐步展开；当前事件优先，主界面只留下一个当前目标与必要动作。使用温灰纸色、墨色、少量旧金与朱印；取消大片发光法阵、彩色 emoji 阵列、重复金框和大面积渐变卡片。

通过内置 imagegen 制作修行场景和山海地图插画，统一干笔水墨、朴素设色和纸张质感。保留人物不指定面貌的黑色剪影要求。真实位图保存在项目 assets 内并离线加载，美术不代替可点击的 HTML 控件。压缩只用于体积优化，记录原稿、生成提示词和正式文件。

## 验收

存档迁移、途中恢复、重复点击、资源上下界、撤退/失败/疗伤、区域解锁、根基突破、不同策略风险差异、全部路线可达；新局真实浏览器操作；六视口布局和重要页面截图复核；全量旧主线与创世回归；生成生产 ZIP、ACCEPTANCE 后线性发布。最终部署只使用本次最后绿色版本。
