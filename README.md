# 我欲飞升 · v1.6.0「宗门时代」

v1.6.0 新增四个轻量宗门：偏剑道的「青云剑宗」、偏肉身的「天罡体宗」、偏吞噬的「万灵吞月谷」与偏悟道/气运的「天机道院」。宗门不是经营后台：没有贡献币、工资、每日任务与职位树，每宗只有一个小幅被动、一份入门传承、三节一次性成长事件和一个宗门大事件。

炼气以后可以谢绝或拜入宗门；谢绝不会锁死路线。宗门事件按炼气 / 金丹 / 化神 / 合体四个境界节点依次出现，高境界才入宗时会按顺序补完已满足的事件，但同一事件只结算一次。入门事件完成后解锁传承，宗门本身同时成为 Build 的真实标签来源；主动离宗后被动、传承与对应 Build 来源立即撤销，不留下隐藏倍率。

宗门大事件固定提供「护宗 / 离宗 / 叛宗」三种明确选择。护宗保留宗门并留下轻量历练增益；离宗和平结束关系；叛宗会记录为不可逆的本世关系，今生不能重新拜入同宗，为后续因果系统预留可追溯来源。主存档由 v8 升级到 v9，旧 v8 只补空宗门态，不伪造历史入宗、事件或宗门关系。

## v1.5.0「秘境降临」

v1.5.0 新增三座短局 Roguelite 秘境：凡人～筑基的「黑风旧窟」3 层、金丹～化神的「丹霞遗府」4 层、炼虚～渡劫前的「界外残境」5 层。每层给出 1～3 条路线，覆盖战斗、灵药、交换、功法残页、禁制与异象；普通层始终至少存在一条非失败路线，最终层为独立 Boss。

秘境的路线、异象和风险判定在进入对应层时由独立确定性 seed 固定，打开面板与刷新不会重抽。玩家任何一层都能「安全退出」：保留已经保底的收益和未保底部分的一半；危险路线失败只结束本次秘境，不会让本世死亡或回退主线。临时破局增益只存在于当前秘境，离开后全部清理。

Boss 首胜才生成独有装备来源，同一秘境重复通关不会重复发放首胜装备。秘境历史只保留最近 12 次摘要；主存档由 v7 升级到 v8，旧 v7 只补空秘境状态，不从旧日志伪造探索历史。状态机以 1,200 个确定性样本覆盖三座秘境的层级、退出、失败与终点。

## v1.4.0「九州历练」

v1.4.0 把凡界狩猎与三眼妖王战斗从“点完立刻只看到结果文本”升级为 **先确定性结算、后播放文字战录**。新模块 `src/combat.js` 接受已经算好的敌我战力、胜率和唯一一次随机结果，返回 `{ result, stateDelta, replayEvents[] }`；主 reducer 仍然只提交一次真实伤害、修为、吞噬和装备掉落，UI 不在动画期间重新掷骰。

战录包含遭遇、攻击、反击、格挡、Build/路线触发、吞噬、胜负与掉落等事件，通常在 1～5 秒内播放完毕，也可以随时「略过」。刷新页面只会读取存档中的同一份 `combatReplay` 重播，不会重抽胜负或重复领取修为/装备；进行下一次真实游戏操作后，旧回放才从主存档中清除。`prefers-reduced-motion` 下所有事件直接显示最终帧。

主存档由 v6 升级到 v7，只新增一份最多 10 条事件的有界 `combatReplay`；v6 旧档迁移只补 `null`，不伪造旧战斗历史。R≥2 的碾压规则继续保持必胜无伤，既有防御、复活、Build、装备、轮回、仙界与无尽逻辑不因表现层改变。

## v1.3.0「万法归一」

v1.3.0 把此前分散在天命、属性、灵根、异变、融合、四槽装备、妖王路线与天劫路线中的信息统一映射为 10 类标准 Build 标签：剑道、雷霆、吞噬、肉身、神魂、气运、悟道、生存、爆发、成长。`src/build.js` 使用纯函数 `evaluateBuild(state)` 输出主脉、辅脉、全部真实来源、激活协同、受控效果与解释文本；打开「查看协同」只读取状态，不推进 revision、不消费 RNG，也不写入存档。

首版 15 条协同覆盖六大道途与跨流派组合，例如雷剑同鸣、以战养道、岳峙不移、照见其理、顺势而生、剑理归一。每条协同都在规则表中公开列出所需标签和当前数值效果，UI 以“来源 → 协同 → 当前效果”展示，不存在无法追溯的隐藏倍率。卸下提供关键标签的装备后，对应协同立即撤销；Build 是当前状态的派生结果，不需要额外存档版本。

v1.2.0 在凡界加入独立四槽装备：兵器、法宝、法衣、佩饰。行囊固定 12 格，现有 24 件基础装备与 9 件本命神兵阶段装备；妖王、天地印证和天劫提供确定性装备来源，部分历练/狩猎按本世种子和不可重复来源键判定，不额外消费主 RNG。装备需要鉴定后才能穿戴，重复或不需要的器物可归炉为「器蕴」，用于无失败温养；阶段名称使用初炼 / 温养 / 通灵 / 圆满，不引入耐久与“+N”强化循环。

三条本命神兵路线分别为剑道「青锋剑胚 → 雷狱剑 → 斩界天锋」、吞噬「噬灵幡胚 → 饕餮玄幡 → 吞天魔幡」、肉身「镇岳尺胚 → 地脉镇尺 → 擎天神岳」。已穿戴本命神兵会从实战、妖王与天劫获得独立历练，达到阈值后确定蜕变；蜕变复用 v1.1.0 的重大事件演出。凡界四槽与仙界肉身 / 血脉 / 神魂 / 神通 / 法则五槽完全分开，飞升不会把凡界装备伪装成仙界五槽材料。

v1.1.0 不改动已经稳定的凡界、轮回、仙界与无尽数值闭环，先把现有体验重新分出游戏层级：境界与战力成为首屏第一焦点，当前事件和主操作紧随其后；修为、吞噬和元气获得使用短促跳字，突破、首次异变、金丹融合、雷劫与飞升共用不可叠加的重大事件演出层。

七阶段背景在原有 SVG 之上增加 CSS 前景薄雾与景深，仍不下载图片或字体。Web Audio 为重大节点增加程序合成瞬态；关闭音效或启用 `prefers-reduced-motion` 不影响任何结算。表现规则集中在 `src/presentation.js`，后续本命神兵进化和更高阶事件可以复用，而不把动画逻辑混入状态机。

v1.0.0 将凡界、轮回、仙界序章、五槽无限进化和无尽诸天收束为同一条正式体验。第一世依然从赤鳞妖蟒的“只能逃”开始，飞升后会在仙界再次被一只噬灵虫压制；第二世则能携一枚道痕重新入山，在开局八选三中看到一张对应的玄品前世天命，并在前世回声、天劫和仙界法则中留下可验证的连续影响。

轮回不是永久战力树。六枚道痕各自只服务下一世：固定加入一张可拒绝、会占正常选择位的前世天命；触发两次叙事回声；在对应天劫增加一条路线。开始下一世后道痕即被消费。主存档记录前世来源 seed，轮回册支持中断后的双存档对账，避免“新世已写入、道痕却仍挂在轮回册”造成重复继承。

仙界序章之后开放五槽进化：肉身、血脉、神魂、神通、法则。25 种槽位特性中包含 4 种融合成果；普通吞噬三择一，可替换、叠合、主动升级至五阶或化为碎片。旧槽被替换后不会继续叠加。四种配方明确列出材料、碎片成本及催化物保留规则。

世界节点为下界仙域 → 仙城废墟 → 星海遗迹 → 法则裂谷 → 世界边缘。四个后续世界各有两类仙兽、一个叙事印证与一个守界者；本界两次吞噬和印证完成后才能挑战界门。每界固定生成一种天地词条与两种仙兽法则，刷新不重抽。守界者提供正面与法则破局路线。

第一轮仙界结局是「世界吞噬者」，随后自愿开启无尽诸天。每过一界尺度扩大四倍，五槽保留，本界炼化重新开始，词条与敌方法则重新组合。没有预设最后一层。数值使用 12 位有效数字加精确字符串指数，超过 10^308 仍可比较、增长、序列化；这是有限精度科学计数，不是无限整数精度。法则碎片/仙元有明确携带上限，历程保留最近 40 条，不随层数无限增加存档体积。

凡界飞升后可选择「踏入仙界」：保留原有结局和轮回道痕，经历界压、仙躯重构、第一次仙界吞噬、六法则中的三选一与噬灵虫复仇。界压统一将凡力与虫的原刻度除以一百万，并非把已有成就清零。仙界成长使用仙元和法则碎片；噬灵虫的势能固定不变。无风险缓炼仙气与藏身调息始终提供恢复路线。

主存档为 v7，兼容旧 v1/v2/v3/v4/v5/v6；v5→v6 只补一份空装备态，v6→v7 只补空战斗回放，不伪造旧世从未获得的装备、掉落来源、器蕴或战斗历史。仙界子存档仍为 v2，并迁移 v0.8.0 的子存档 v1。旧通关档仍停在原结局，只有主动进入才建立或扩展仙界道途。自动点击通过不等于已验证 10～20 分钟真人时长。

新增山野、云上、界外、天门四层本地合成环境音乐，以及天命、突破、吞噬、异变、融合、妖王、雷劫、飞升和道痕九类音效。顶部「音景」可分别关闭音乐/音效、调整音量。首次真实交互后启动，失焦或隐藏页面暂停。没有录制 BGM、音频下载、收费服务或外部音源，音景是原创程序合成的低声部与稀疏五声音阶拨弦。

本版新增首局命册批注、安全连续闭关和「寻天地印证」入口；战力主显示改为万/亿并可点按查看全数。印证本来就首次历练保底，因此不会自动替玩家处理事件。无暇飞升使用持久败退记录，旧档缺记录不伪造称号；逆寿成仙按入劫前寿元判定。

《我欲飞升》是一款手机竖屏优先的离线文字修仙 Roguelike。玩家从凡人起步，抽取天命、自由加点、修炼破境、吞噬旧敌、获得异变并完成能力融合，再让本世 Build 决定三眼妖王、天地印证与三重天劫的破局方式。

凡界、轮回、声境、仙界和无限进化全部离线运行。核心结构仍然是：**这一刻无法撼动的庞然大物，最终成为下一口修为；进入更大的世界后，再重新学会弱小。**

### 本命神兵与四槽装备

凡界装备只增强当前本世 Build，不是新的永久养成货币树。四个槽位各最多穿戴一件；未鉴定装备不生效，穿戴后才由主战力、修为、承伤、神识、气运等现有公式读取。装备背包最多 12 件，满包后的新掉落直接折算器蕴，避免无限膨胀存档。

掉落以 `seed + 来源键 + 事件类型 + 境界/路线` 生成；同一个来源键只结算一次，因此刷新、导出再导入或重复点击都不能重领。三眼妖王必定留下本命神兵初胚，天地印证必定有装备结算，天劫可根据路线产生本命神兵；普通历练和狩猎则保留较低出现率。鉴定免费，温养只消耗归炉所得器蕴且没有失败率。本命神兵历练仅在装备于兵器槽且已经鉴定时增长。


然后打开 `http://127.0.0.1:4317`。

## Cloudflare 部署

仓库已提供 `wrangler.jsonc`，静态资源目录固定为 `./dist`。Cloudflare 构建时应先执行 `npm run build`，再执行 `npx wrangler deploy`；Wrangler 只会上传构建后的生产文件，不会把仓库根目录、`node_modules`、测试或截图当作静态资源上传。

```sh
npm run build
npm run deploy
```

生产运行不需要安装第三方依赖。游戏只使用本地脚本、系统字体和自包含 SVG，没有 CDN、联网接口、广告或外部资源。`file://` 与本地 HTTP 地址属于不同浏览器存储域，可通过 JSON 导出和导入转移本世存档与轮回册。

## 正式版核心

### 六类本世道途识别

游戏会根据真实天命、属性、异变、融合、妖王路线和渡劫路线，实时判断本世最接近的流派：

| 道途 | 主要信号 |
| --- | --- |
| 吞噬进化流 | 吞噬天命、吞噬次数、妖蟒血、吞天魔胃、吞噬破局 |
| 雷剑破界流 | 青云剑诀、剑心、剑骨、雷剑体、剑道破局 |
| 不灭肉身流 | 高根骨、赤鳞、金刚真身、肉身承劫 |
| 神魂妖瞳流 | 高神识、蛇瞳、九幽妖瞳、看破妖眼与心魔 |
| 天命气运流 | 高气运、气运天命、天命护体、命数路线 |
| 悟道归一流 | 高悟性、修炼天命、五行归一、明心见道 |

命册与主界面会显示当前道途、形成阶段、判定依据和下一步可能的成长方向。该识别只解释已有 Build，不改变战斗公式。

### 命途图谱

图谱现在同时记录凡界与仙界内容，包括：

- 24 条普通天命与 6 条前世天命；
- 3 种首次异变；
- 8 种金丹融合；
- 15 类天地印证；
- 6 种三眼妖王破局方式；
- 18 种渡劫法门，包括六枚道痕路线；
- 9 个飞升称号；
- 6 枚轮回道痕；
- 12 段前世回声；
- 6 种仙界法则；
- 25 种五槽进化特性、4 种仙界融合，以及四个后续世界节点。

只记录玩家真正见过或达成的内容。未发现条目显示 `？？？` 和条件线索，不提供付费解锁，也不会因为刷新而重抽。

### 飞升称号

同一局可以同时满足多个称号，结算页优先显示更具体的一项。当前包括：万妖归腹、一剑开天、不灭道躯、照破诸妄、天命所归、朝闻大道、无暇飞升、逆寿成仙和凡界飞升者。

### 六枚一次性轮回道痕

| 道痕 | 下一世影响 | 对应天劫路线 |
| --- | --- | --- |
| 噬界残痕 | 固定出现玄品「前世饥火」 | 天门终劫吞纳余光 |
| 剑心余烬 | 固定出现玄品「旧世剑意」 | 天门终劫以前世余烬叩门 |
| 不灭骨印 | 固定出现玄品「前尘道骨」 | 九霄雷劫唤醒骨印承雷 |
| 照幽灵纹 | 固定出现玄品「前尘照心」 | 问心魔劫照破心魔 |
| 天命余辉 | 固定出现玄品「旧命相随」 | 天门终劫借旧命开门 |
| 悟道残卷 | 固定出现玄品「一念前知」 | 问心魔劫翻卷明心 |

飞升或死亡后，结算页根据本世实际倾向提供候选，只能凝练一枚。开始下一世时，道痕被写入新存档并从轮回册中消费；它不会自动传到第三世。前世天命本身会有轻量真实效果，但必须占用一个正常天命选择位，不能绕过开局三选限制。

### 连续闭关

普通“闭关”仍保留。新增“闭关至当前桎梏”，用于减少中后期机械点击。连续闭关会在以下任一条件出现时立即停止：

- 赤鳞妖蟒等强制遭遇出现；
- 当前境界修为圆满；
- 寿元进入危险区；
- 状态离开可闭关阶段。

连续闭关不会替玩家突破、处理事件、选择天命或渡劫。

## 工程结构

- `src/data.js`：普通/前世天命、灵根、境界、敌人、异变、融合、事件和六枚道痕配置。
- `src/engine.js`：确定性状态机、凡界战斗、渡劫、v1→v5 迁移与仙界子状态接入。
- `src/meta.js`：流派识别、称号、跨世图谱、轮回册、来源记录和道痕消费/恢复规则。
- `src/immortal.js` / `src/evolution.js` / `src/quantity.js`：仙界序章、五槽进化、四界主线、无尽模式和有限精度超大数值。
- `src/presentation.js`：品质令牌、奖励跳字与重大事件演出规格；纯表现层，不消费游戏 RNG。
- `src/app.js`：页面 UI、本世存档、轮回册、命册、图谱、结算和导出。
- `src/scenes.js` / `src/style.css`：境界背景、事件气氛、动效与响应式视觉。
- `tests/engine.test.cjs`：状态机边界、完整路线和 800 局随机仿真。
- `tests/meta.test.cjs`：流派、称号、图谱、轮回册和道痕测试。
- `tests/scenes.test.cjs`：场景映射、生产资源和异步背景切换测试。
- `tools/run-browser-qa.cjs`：隔离浏览器完整流程、视觉矩阵和导出验收。
- `tools/build.cjs` / `tools/verify-release.cjs`：正式包构建与内容校验。
