# 我欲飞升 · v0.8.0「仙界初临」

凡界飞升后可选择「踏入仙界」：保留原有结局和轮回道痕，经历界压、仙躯重构、第一次仙界吞噬、六法则中的三选一与噬灵虫复仇。界压统一将凡力与虫的原刻度除以一百万，并非把已有成就清零。仙界成长使用仙元和法则碎片；噬灵虫的势能固定不变。无风险缓炼仙气与藏身调息始终提供恢复路线。

主存档升级为 v5：兼容旧 v1/v2/v3/v4，旧通关档仍停在原结局，只有主动进入才建立仙界子存档 v1。序章目标是吞噬固定噬灵虫；此版本尚未提供仙界后段或无尽模式，后续阶段将单独验收发布。自动点击通过不等于已验证 10～20 分钟真人时长。

新增山野、云上、界外、天门四层本地合成环境音乐，以及天命、突破、吞噬、异变、融合、妖王、雷劫、飞升和道痕九类音效。顶部「音景」可分别关闭音乐/音效、调整音量。首次真实交互后启动，失焦或隐藏页面暂停。没有录制 BGM、音频下载、收费服务或外部音源，音景是原创程序合成的低声部与稀疏五声音阶拨弦。

本版新增首局命册批注、安全连续闭关和「寻天地印证」入口；战力主显示改为万/亿并可点按查看全数。印证本来就首次历练保底，因此不会自动替玩家处理事件。无暇飞升使用持久败退记录，旧档缺记录不伪造称号；逆寿成仙按入劫前寿元判定。

《我欲飞升》是一款手机竖屏优先的离线文字修仙 Roguelike。玩家从凡人起步，抽取天命、自由加点、修炼破境、吞噬旧敌、获得异变并完成能力融合，再让本世 Build 决定三眼妖王、天地印证与三重天劫的破局方式。

v0.6.0 保留 v0.5.1 的完整凡界主线和七阶段境界背景，在飞升终点之后建立第一层跨局结构：**一世结束后识别本世流派，记录图谱与称号，并从最鲜明的三条道途中凝练一枚一次性轮回道痕。**道痕不会永久叠加战力，只影响下一世的开局天命，并在对应天劫开启一次额外路线。

## 打开试玩

直接双击项目根目录 `index.html`，或在本目录执行：

```sh
npm start
```

然后打开 `http://127.0.0.1:4317`。

生产运行不需要安装第三方依赖。游戏只使用本地脚本、系统字体和自包含 SVG，没有 CDN、联网接口、广告或外部资源。`file://` 与本地 HTTP 地址属于不同浏览器存储域，可通过 JSON 导出和导入转移本世存档与轮回册。

## v0.6.0 新增内容

### 六类本世道途识别

游戏会根据真实天命、属性、异变、融合、妖王路线和渡劫路线，实时判断本世最接近的流派：

| 道途 | 主要信号 |
| --- | --- |
| 吞噬进化流 | 吞噬天命、吞噬次数、妖蟒血、吞天魔胃、吞噬破局 |
| 雷剑破界流 | 青云剑诀、剑心、剑骨、雷剑体、剑道破局 |
| 不灭肉身流 | 高根骨、赤鳞、金刚真身、肉身承劫 |
| 神魂妖瞳流 | 高神识、蛇瞳、九幽妖瞳、看破妖眼与心魔 |
| 天命气运流 | 高气运、气运天命、天命护体、命数路线 |
| 悟道归一流 | 高悟性、修炼天命、五行归一、明心见道 |

命册与主界面会显示当前道途、形成阶段、判定依据和下一步可能的成长方向。该识别只解释已有 Build，不改变战斗公式。

### 命途图谱

图谱共有 89 项可发现内容，按八类保存：

- 24 条天命；
- 3 种首次异变；
- 8 种金丹融合；
- 15 类天地印证；
- 6 种三眼妖王破局方式；
- 18 种渡劫法门，包括六枚道痕路线；
- 9 个飞升称号；
- 6 枚轮回道痕。

只记录玩家真正见过或达成的内容。未发现条目显示 `？？？` 和条件线索，不提供付费解锁，也不会因为刷新而重抽。

### 飞升称号

同一局可以同时满足多个称号，结算页优先显示更具体的一项。当前包括：万妖归腹、一剑开天、不灭道躯、照破诸妄、天命所归、朝闻大道、无暇飞升、逆寿成仙和凡界飞升者。

### 六枚一次性轮回道痕

| 道痕 | 下一世影响 | 对应天劫路线 |
| --- | --- | --- |
| 噬界残痕 | 开局至少出现一道吞噬天命 | 天门终劫吞纳余光 |
| 剑心余烬 | 开局至少出现一道剑道天命 | 天门终劫以前世余烬叩门 |
| 不灭骨印 | 开局至少出现一道肉身天命 | 九霄雷劫唤醒骨印承雷 |
| 照幽灵纹 | 开局至少出现一道神魂天命 | 问心魔劫照破心魔 |
| 天命余辉 | 开局至少出现一道气运天命 | 天门终劫借旧命开门 |
| 悟道残卷 | 开局至少出现一道修炼天命 | 问心魔劫翻卷明心 |

飞升或死亡后，结算页根据本世实际倾向提供三枚候选，只能凝练一枚。开始下一世时，道痕被写入新存档并从轮回册中消费；它不会自动传到第三世，也不会直接增加基础属性、修为或战力。

### 连续闭关

普通“闭关”仍保留。新增“闭关至当前桎梏”，用于减少中后期机械点击。连续闭关会在以下任一条件出现时立即停止：

- 赤鳞妖蟒等强制遭遇出现；
- 当前境界修为圆满；
- 寿元进入危险区；
- 状态离开可闭关阶段。

连续闭关不会替玩家突破、处理事件、选择天命或渡劫。

## 完整凡界主线

```text
八选三先天天命
→ 分配 20 点属性
→ 随机灵根 / 出身
→ 初遇赤鳞妖蟒并逃生
→ 炼气
→ 筑基
→ 回来碾压并吞噬妖蟒
→ 第一次异变
→ 金丹
→ 第一次能力融合
→ 三眼妖王
→ 元婴
→ 化神
→ 炼虚
→ 合体
→ 大乘
→ 渡劫
→ 九霄雷劫 / 问心魔劫 / 天门终劫
→ 飞升
→ 仙界噬灵虫彩蛋
→ 凝练一枚轮回道痕
→ 下一世消耗道痕重新入山
```

赤鳞妖蟒始终固定 150 战力。第一次相遇时正常玩家只能逃生；筑基后它没有同步升级，因此旧敌会真正从威胁变成食物。有效战力达到碾压区间后必胜，不会出现高出数倍却随机暴毙。

## 当前系统

- 24 条有真实数值效果的天命；开局八选三，每次大境界突破再三选一。
- 根骨、悟性、气运、神识四属性；20 点自由分配和四套推荐方案。
- 5 种灵根、4 种出身。
- 凡人、炼气、筑基、金丹、元婴、化神、炼虚、合体、大乘、渡劫完整境界链。
- 22 类敌人，从食气灵虫、赤鳞妖蟒到太古龙魂和天外邪神投影。
- 赤鳞、蛇瞳、妖蟒血三种首次吞噬异变。
- 8 种金丹融合，并由本世条件生成三项候选。
- 8 类筑基/金丹 Build 条件事件，以及 15 类元婴至大乘世界事件。
- 元婴至大乘每境至少完成一次天地印证才能继续破境。
- 三眼妖王根据神识、剑道、吞噬、肉身、气运和正面战力开放不同路线。
- 三段式渡劫，记录每一劫实际采用的路线。
- 七阶段境界背景、Boss/妖蟒/雷劫/飞升气氛与低强度 CSS 动效。
- 自动存档、轮回册、JSON 分别导出/导入、损坏数据拦截、重开确认和命格 PNG 导出。
- v1 / v2 / v3 本世存档自动迁移到当前存档格式 v4。

## 存档与轮回册

本世存档与跨局资料分开保存：

- 本世存档格式 v4：当前境界、Build、因果、妖王路线、三劫路线与携带道痕；
- 轮回册格式 v1：图谱、称号、历世统计、最近 50 世摘要与下一世待继承道痕。

导入本世存档不会覆盖轮回册；导入轮回册也不会改变正在进行的一世。旧版完成存档迁移后保留原结局，但无法凭空补记旧版没有记录的具体妖王或天劫路线。

## 工程结构

- `src/data.js`：天命、灵根、境界、敌人、异变、融合、事件和六枚道痕配置。
- `src/engine.js`：确定性状态机、战斗、破境、连续闭关、妖王、天地印证、渡劫和 v1→v4 迁移。
- `src/meta.js`：流派识别、称号、图谱、轮回册和道痕候选/消费规则。
- `src/app.js`：页面 UI、本世存档、轮回册、命册、图谱、结算和导出。
- `src/scenes.js` / `src/style.css`：境界背景、事件气氛、动效与响应式视觉。
- `tests/engine.test.cjs`：状态机边界、完整路线和 800 局随机仿真。
- `tests/meta.test.cjs`：流派、称号、图谱、轮回册和道痕测试。
- `tests/scenes.test.cjs`：场景映射、生产资源和异步背景切换测试。
- `tools/run-browser-qa.cjs`：隔离浏览器完整流程、视觉矩阵和导出验收。
- `tools/build.cjs` / `tools/verify-release.cjs`：正式包构建与内容校验。
